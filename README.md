# OX Connections – Inventory Management System

A full-stack Inventory Management System built using:

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Authentication: JWT + bcrypt
- Charts: Chart.js
- Deployment:
  - Backend: Render
  - Frontend: Netlify

## Features
- Admin authentication
- Product, Order, Customer & Supplier management
- Inventory tracking with low-stock alerts
- Real-time dashboard analytics
- Secure REST APIs with JWT protection

## How it works
1. Admin logs in
2. JWT token stored in browser
3. Protected routes use Authorization header
4. Dashboard fetches analytics from backend
5. Charts visualize business data
